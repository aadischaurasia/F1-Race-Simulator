# F1-Race-Simulator

A Python-based F1-style race simulation project focused on vehicle behaviour, telemetry, tyre wear, fuel usage, pit stops and race strategy.

## About the Project

I am developing this project to explore how programming, simulation and data analysis can be applied to motorsport.

The simulator is built in Python using Pygame and Pandas. It is being developed step-by-step, starting with basic vehicle movement and gradually adding telemetry, tyre behaviour, fuel modelling, pit stops and race-strategy features.

## Current Features

- 2D vehicle simulation
- Acceleration and braking
- Gears and RPM
- Vehicle physics
- Lap timing
- Sector timing
- Telemetry recording
- Fuel consumption
- Fuel mass affecting vehicle mass
- Soft, Medium and Hard tyre compounds
- Tyre wear
- Pit lane
- Pit box
- Pit stops
- Pit-stop tyre selection
- Basic tyre-based strategy decisions

## Technologies

- Python
- Pygame
- Pandas
- CSV
